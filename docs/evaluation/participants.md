## Notes on PT-8 (the 29 Oct session)

On 1 Nov the team decided to count the 29 Oct session as think-aloud participant **PT-8**. It was first run as a pilot, so these facts must be stated in the report:

- **Earlier prototype.** It ran on the prototype before the wiring fixes, and with the first task wording. It found the "station" collision, which was fixed before the other sessions. So PT-8 saw a different version from every later participant.
- **Partial session.** It ran 3:40. The notes show T1 and T2 reached, with T2 not completed, so it is a partial run of the five tasks.
- **Laptop, not a phone.** The participant described working "on the desktop on the fake prototype". A laptop session is valid, but the report must say which device each participant used.
- **Report wording.** Section 3.4 of the report calls this session "the pilot" and says the rename was made "before any participant session". If PT-8 counts, that wording must change.

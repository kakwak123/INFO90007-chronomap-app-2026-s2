## Notes on the pilot (29 Oct, not counted)

**Device was a laptop, not a phone.** The transcript opens with the participant describing working
"on the desktop on the fake prototype". The study kit's first choice is a phone, because standing
at a landmark holding a phone is the real context. A laptop session is still valid, but the report
has to say which device each participant used, and a laptop participant cannot react to the
one-handed, outdoors reality the design assumes. Worth getting every counted participant onto a phone so
the pilot is the exception rather than the pattern.

**The session ran 3:40.** The protocol budgets about 25 minutes for five tasks. The findings file
shows T1 and T2 reached, with T2 not completed. So this reads as a **pilot or a partial session**
rather than a full run.

That matters for two reasons, and it is better to settle it now than at write-up:

1. If it was a pilot, it is genuinely useful - it already surfaced the "station" word collision,
   which is worth fixing before anyone else sits down - but it should not be counted as one of the
   five think-aloud participants, and a sixth person is needed.
2. If it was a full session that simply ended early, the report must say so and explain why, since
   a reader comparing a 3:40 session against a five-task protocol will notice.

Either answer is defensible. Leaving it ambiguous is not.

## What the report can honestly cite

A2 lost marks for references that were "too few or chosen arbitrarily", so citations added to look
thorough carry a real risk. These five are places where the report already rests on subject content
and simply does not credit it.

| Claim already in the report | Cite | Why it holds |
| --- | --- | --- |
| Methods 2.4, why think-aloud and why a questionnaire | Lecture 9, Tutorial 10 | The lecture sets the observational-plus-query requirement and tells students to justify the choice |
| Methods 2.3, Nielsen's ten heuristics | Tutorial 10 | All ten are taught there, one per slide |
| The design space: co-located, synchronous | Lecture 3, Week 7 | Directly answers the A2 deduction that the design space "is not adequately justified" |
| Crowdsourcing *and* collaborative, not either alone | Tutorial 4 | Its four-mode table defines exactly where this project must sit |
| The 3C model | Week 2 reading | Fills an empty placeholder in the bibliography |

Tutorial 4 also cites **Hosio, Goncalves, van Berkel, Klakegg, Konomi and Kostakos (2018)** on
facilitating collocated crowdsourcing. That is a real peer-reviewed reference, set by the subject,
on precisely the design space A2 was marked down for. It is the strongest single citation
available here.

### One structural gap

Tutorial 6 lists the required report structure as Introduction, **Related Work**, Method, Results,
Discussion, Conclusion, References.

The current report has no Related Work section. The material exists and is good, including the
comparison table and the prior-art citations, but it sits inside Discussion 4.3 rather than
standing as its own section where the tutorial puts it. Tutorial 6 is explicit that Related Work
must say how the solution differs from what exists.

Moving that content up is largely a cut and paste and costs no words. Worth doing before
submission.

### Before this gets pushed

The GitHub repository is public. These are the university's copyrighted slides and readings, about
19 MB, and pushing them republishes material that is not ours, which is a separate problem from
anything in the assignment. The same applies to the lecture transcripts already in the repository.

Recommended: add `docs/course-materials/` and `docs/lecture-transcripts/` to `.gitignore`. Every
file stays available locally for reference and citation; nothing copyrighted is published.
